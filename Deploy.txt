
**MERN Deployment Flow**

```text
React Frontend
        │
        ▼
Netlify / Vercel

        │

HTTP Request (Axios)

        ▼

Express Backend
        │
        ▼
Render

        │
        ▼

MongoDB Atlas
```

> **Note:** Netlify/Vercel **frontend-ku mattum**. Express backend-a **Render** (or Railway) la host pannanum.

# One Important Thing

In Express, enable CORS for your deployed frontend.

Example:

```javascript
const cors = require("cors");

app.use(
  cors({
    origin: "https://your-netlify-app.netlify.app"
  })
);
```

During development, `app.use(cors())` is fine. For production, it's better to restrict the allowed origin to your frontend URL.

# Final Architecture

```text
User
 │
 ▼
Netlify / Vercel (React)
 │
 │ Axios
 ▼
Render (Express API)
 │
 ▼
MongoDB Atlas
```

💡 **One correction:** If your React project is **Create React App** (your project has `App.js` and uses `npm start`), use **`build`** as the publish directory. If it's a **Vite** project, use **`dist`** instead.
